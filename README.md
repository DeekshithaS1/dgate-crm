# DGATE CRM – Customer Relationship Management System

A web-based CRM system developed to **manage leads, employees, managers, and customer follow-ups** through a centralized platform.

## 🔗 Live Demo

🌐 **[Visit DGATE CRM](https://www.extrominds.com/)**

## 🛠️ Technologies

* React.js
* JavaScript
* Node.js
* Express.js
* MySQL
* REST APIs
* Axios
* Recharts
* HTML
* CSS

## ✨ Key Features

* Lead management
* Employee management
* Manager dashboard
* Lead search and filtering
* Follow-up management
* Lead status tracking
* Employee performance tracking
* Reports and data visualization
* Role-based functionality
* Authentication
